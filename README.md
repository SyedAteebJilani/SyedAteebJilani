## 🚀 Smart File Optimizer & Task Scheduler

**A Windows-native utility engineered for automated duplicate detection and disk-space recovery.**

🔗 Repository:  
https://github.com/SyedAteebJilani/Smart-File-Optimizer-Task-Scheduler-

### Highlights

- Multi-threaded hashing engine powered by a worker-pool architecture.
- Efficient task scheduling using a non-preemptive binary heap.
- Native Windows Recycle Bin integration for safe deletion.
- Optimized for high-throughput disk scanning.
- Handles large datasets with minimal CPU overhead.
- Delivers approximately **50% faster scan throughput** compared to single-threaded approaches.

### Stack

`Python` • `CustomTkinter` • `threading` • `queue` • `hashlib` • `send2trash`
